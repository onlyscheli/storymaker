
# 🎀 StoryMaker

**Create your story. Your vibe. ♡**

StoryMaker ist ein kostenloses, ästhetisches Tool zum Erstellen von Instagram Stories. Gestalte individuelle Story-Designs mit schönen Farben, Texten, Stickern und eigenen Fotos – direkt im Browser.

## ✨ Features

- 🎨 Ästhetische Story-Vorlagen
- 🌸 Rosa-, Beige-, Lavendel- und weitere Farbpaletten
- ✍️ Eigene Texte und anpassbare Schriftgrößen
- ♡ Sticker und verschiedene Textausrichtungen
- 🖼️ Eigene Fotos hinzufügen
- 📱 Story-Designs im Instagram-Story-Format (9:16)
- 📥 Story als PNG herunterladen
- 🎲 Story-Ideen wie „This or That“ und „Who knows me best?“
- 💬 Captions und Hashtags kopieren
- 📲 Optimiert für Smartphones und Computer

## 💗 Kostenlos und einfach

StoryMaker benötigt:
- Keine KI-API
- Keinen eigenen Server
- Kein Backend
- Keine Anmeldung
- Keine kostenpflichtigen Dienste

Die Website funktioniert direkt im Browser. Eigene Fotos werden lokal verarbeitet und nicht an einen eigenen Server übertragen.

## 📖 Installation

1. Repository auf GitHub öffnen.
2. Die Datei `index.html` herunterladen oder klonen.
3. `index.html` im Browser öffnen.

## 🌐 GitHub Pages aktivieren

1. Öffne **Settings** in deinem GitHub-Repository.
2. Wähle **Pages**.
3. Wähle unter **Build and deployment** die Option **Deploy from a branch**.
4. Wähle den Branch `main` und den Ordner `/ (root)`.
5. Klicke auf **Save**.
6. Warte, bis deine Website veröffentlicht wurde.

## 📱 Für Instagram

Teile StoryMaker über deine Instagram-Bio und zeige in Reels, wie du in wenigen Sekunden eine eigene ästhetische Story erstellst.
